先に結論：無料の入口は3つ、役割が違う

要点　無料で触れる入口は3つあります。自分で解く「WASM Postflop」、解いた結果を引く「フロップ早見盤」、頻度で練習する「GTO Coach」です。

ただし、当サイトの数字はヘッズアップが中心で、条件を決めるのは自分です。

GTOソルバーとは：計算で「得をしない状態」を探す

GTOソルバーは、両者がこれ以上戦略を変えても得をしない状態を、計算で探すプログラムです。ナッシュ均衡に近い状態を探す、と言い換えられます。

ポーカーでは、レンジ、ボード、ベットサイズの選択肢を入れると、手ごとに「ベット・チェック・コール・降り・レイズ」の頻度を返します。

  • レンジ：各局面で持ちうる手の集まり（例：BTNがオープンする手）。
  • ボード：フロップなど、場に出ているカード。
  • ベットの木：どのサイズ・どのレイズを許すかの設定。

無料のものでも、この計算そのものはできます。違いは、入力の手間と、計算にかかる時間と、使える範囲の広さです。

自分で解くなら：WASM Postflop

WASM Postflopは、ブラウザ上で動く無料のオープンソースのソルバーです。ページのタイトルは「Free GTO Solver for Web Browser」でした（2026年11月28日に確認）。

ライセンスはAGPL-3.0です。開発者は、2023年10月に開発を中断したと公式ページに書いています。

メモリは数字のとおり大きいので、端末の空きに注意してください。

ソフトは中断されていますが、無料で動くことは確かめました。

実際にやったこと：入力の手順と地雷

当方がBTN対BBの7枚を解いたときの手順を、順番に書きます。

  1. レンジを用意する：BTNのオープンとBBのコールを、自サイトのプリフロップ表から作って入力しました。
  2. ポットとスタックを入れる：整数しか入らないため、ポット5.5bbを「55」、残り97.5bbを「975」と10倍で入れました。
  3. ベットの木を作る：BTN 33%と75%、レイズ3倍、ターン66%、リバー75%（レイズ無し）にしました。
  4. 精度を決めて回す：誤差0.3%ポットで止めました（2026年10月18日の設定）。
  5. 結果の表を読む：行動の頻度を、ボードごとに写し取りました。

レーキ付きの木は収束が遅く、約1,000秒回しても誤差0.59%までしか下がりませんでした（2026年の実測）。

レンジの用意は自分の作業になります。ここが、いちばん手間のかかる部分です。

誤差の見方：0.3%ポットとは何か

ソルバーの結果には「誤差」が付きます。当サイトの数字は、誤差0.3%ポットで計算を止めたものです。

この誤差は、搾取可能性（エクスプロイタビリティ）と呼ばれる指標で、解が均衡からどれだけ離れているかを、ポットに対する割合で表します。

誤差が小さくても、レンジや木の設定が違えば答えは変わります。誤差は「計算の仕上がり」を示すだけで、「設定の正しさ」は保証しません。

また、誤差を小さくするほど計算に時間がかかります。目的に合わせて、止めどころを決めるのが現実的です。

結果を引くなら：早見盤

同じ種類のソルバーで解いた結果を、板ごとに引ける表にしたのが、当サイトの早見盤です。解く手間は要りません。

表の数字を読むためにレンジを組む必要もありません。代表7枚は、そのまま早見盤のページで見られます。

練習するなら：GTO Coach

GTO Coachは、頻度を答えるクイズです。プリフロップからリバーまでを扱い、無料・登録不要で使えます。現金や賭け金は扱いません。

見るだけで終わらず、手を動かして確かめたい人向けです。

早見盤の数字を見たあとに、同じ種類の局面を自分の判断で答えてみると、頻度の感覚が定着しやすくなります。

  • プリフロップのオープンレンジを、ポジション別に練習できる。
  • 毎回の回答に、正誤と日本語の理由が返る。
  • ルールが不安なら、先にポーカー ルール入門で役と流れを確認できる。

まとめ：無料でも、入口を使い分ければ足りる

結論　自分で解くならWASM Postflop、結果を引くなら早見盤、練習するならGTO Coach。

どれを使うかは、手間をかけて確かめたいのか、数字だけ見たいのかで決まります。

最初の1歩は、フロップ早見盤で代表7枚を見ることです。

そのあと、下のボタンから無料のクイズで確かめられます。

  • 解く：WASM Postflop（レンジの用意と時間が要る）。
  • 引く：フロップ早見盤（代表7枚・解く手間なし）。
  • 練習する：GTO Coach（無料・登録不要）。
