# GTO Coach — 全ストリート対応ポーカートレーナー（旧Preflop Coach）

> TL;DR: 依存ゼロの単一HTML。クイズ（1問1答）＋キャッシュ/トーナメントのフルゲームモード。毎アクションに「正誤＋日本語の理由」をコーチが返す。開くだけで動く。

## 現状（v4 / 2026-07-15）

### 📝 クイズモード（1問1答）
- **Lv1 オープンレンジ**: UTG/HJ/CO/BTN/SB のレイズorフォールド判定
- **Lv2 vsオープン**: BTN vs CO / BB vs BTN（3ベット/コール/フォールド）
- **Lv3 vs3ベット**: CO vs BTN 3bet / BTN vs SB 3bet（4ベット/コール/フォールド）
- 毎回答に ✅/❌/🟡ミックス ＋ ハンドカテゴリ別の日本語解説（テンプレート生成、APIコストゼロ）
- 13x13レンジ表表示、正答率・連続正解を localStorage に記録

### 💵🏆 ゲームモード（キャッシュ / トーナメント）
- 6人テーブル・ボット5人。プリフロップ〜リバーの一連の流れをスタックがなくなるまでプレイ
- **キャッシュ**: 100bb持ち・ブラインド1/2固定・ボットは毎ハンド100bbに補充
- **トーナメント**: SNG形式6人・1500点持ち・8ハンド毎にブラインド上昇（10レベル）・バーストで順位、全員飛ばせば優勝
- **毎アクションにコーチ判定**: プリフロップはチャート照合、ポストフロップは役分類＋モンテカルロ勝率vs必要勝率（ポットオッズ）で ✅/🟡/❌ ＋理由。セッション通算「コーチ評価」を採点
- エンジン: 7枚役判定・サイドポット・オールイン・ヘッズアップブラインド対応。ボットAIはプリフロップ強さ順位（初回MC生成・キャッシュ）＋ポストフロップ勝率ベース

### v4: GTO精度強化
- プリフロップ: ソルバー由来52チャート（poker-charts [MIT] のGreenline/pekarstas、頻度付き）。判定・レンジ表・クイズ全てGTO頻度ベース
- ボットもチャート頻度でプレイ（プリフロップはGTO準拠）
- ポストフロップ: 相手のプリフロップレンジ整合モンテカルロ勝率＋MDF/SPR/ボードテクスチャ解説
- クイズLEVEL4（vs4ベット）追加、47マッチアップ
- キャッシュは100BB/300BB切替（ディープ戦略注記付き）
- v3: ポカチェ風アニメ調UI（カットイン/配牌アニメ/勝利演出）

## 動かす

公開URL: **https://shoubu-lab.com**（旧Vercel URLはリダイレクト）。更新は編集→commit→push（Cloudflare Pagesが自動デプロイ）。ローカルは `index.html` をブラウザで開くだけ。ローカルサーバーは `.claude/launch.json` の `poker-trainer`（port 8931、scratchpad経由配信）。

## /betting/ — ベッティングシステム検証室（2026-09-02 追加）

同じドメイン（shoubu-lab.com）配下のサブディレクトリに置いた、独立した静的セクション。
**新規サブドメインは作らない**方針に従い `/betting/` に配置している（GTO Coach 本体のコードには一切触れていない。
本体側の変更は index.html フッターへの1リンク追加と sitemap.xml のみ）。

| URL | ファイル（＝正本。生成物ではない） |
|---|---|
| /betting/ | `betting/index.html`（ハブ・5種比較・全システム切替シミュレータ） |
| /betting/martingale | `betting/martingale.html` |
| /betting/montecarlo | `betting/montecarlo.html` |

| /betting/cocomo | `betting/cocomo.html` |
| （共通） | `betting/app.js`（エンジン＋UI）／`betting/app.css` |

- **編集するのは上のHTML/JS/CSSそのもの**。ビルド工程もジェネレータも無い。
- 各ページは `<div id="sim" data-system="..." data-game="...">` を置くだけでシミュレータが起動する。
  `data-system` を省いた場合は5種を切り替えられるフル版になる（ハブがこれ）。
- **自己テスト**：URLの末尾に `#selftest` を付けて開くと27件の不変条件テストが走る
  （進行ルール／会計／再現性／期待値の同一性を8ゲーム全列挙で厳密検証／自動再生の世代ガード／表示と内部状態の一致）。
  **JSを触ったら必ずこれを実行して PASS 27 / FAIL 0 を確認してから push すること。**
- **非同期は自動再生の setTimeout 1本だけ**。`autoTimer`（ハンドル）と `autoToken`（世代番号）で管理し、
  タブ切替・設定変更・リセットで必ず停止＋所有DOMの完全再描画を行う。部分更新はしない。
- 解説ページに載せている実測値は、シミュレータに**乱数シード 20260902 ／ セッション数 5,000**を入れれば再現できる。
  数字を書き換えるときは、必ず同じ手順で実測し直すこと。
- 方針：「勝てる攻略法」としては絶対に書かない。射幸心を煽る表現を使わない。
  全ページに「現金・賭け金・賞金・ポイント等を一切扱わず、換金・出金の仕組みもありません」を明記している（削除禁止）。
